# Ryde for Android

The Android apps for Ryde (ryde.bz), until they are on Google Play.

- **Ryde**: book a licensed taxi, rent a vehicle, book a tour. Download: https://ryde.bz/download/ryde.apk
- **Ryde Driva**: for licensed taxi drivers. Download: https://ryde.bz/download/ryde-driva.apk

On your phone: open the link, tap the file when it finishes, and allow your browser to install apps if Android asks.
On an iPhone, get Ryde on the App Store.
